# English Adventure: Little Town

Браузерная обучающая игра: английский язык уровня Pre-A1 для детей и подростков 6–15 лет.
Ребёнок живёт в маленьком городке, помогает жителям, собирает коллекцию — и учит английский через задания, а не через тесты.

**Статус:** Этап 0 — архитектура и форматы данных. Код игры ещё не написан.

## Что уже есть

- `schemas/` — JSON Schema для словаря, фраз, предметов, персонажей, диалогов, квестов, навыков и файла сохранения.
- `content/` — пример: 40 слов, 13 фраз, 6 навыков и первый квест «Синяя чашка для мамы» с двумя диалогами.
- `tools/validate-content.mjs` — проверка контента: схемы, ссылки, графы диалогов, зависимости квестов, выполнимость навыков.
- `tests/` — 16 автотестов: валидатор ловит типичные ошибки, схема сохранения отклоняет порчу и лишние личные данные.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run validate-content          # проверить контент
npm run validate-content:assets   # + наличие картинок и аудио (после этапа 2)
npm test                          # автотесты
```
