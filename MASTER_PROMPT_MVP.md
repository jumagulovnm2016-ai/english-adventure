# MASTER PROMPT — ENGLISH ADVENTURE (MVP)
## Браузерная обучающая игра: английский для детей, уровень Pre-A1

**Рабочее название:** English Adventure — Little Town
**Версия документа:** MVP v1 (заменяет полную версию концепции на время разработки MVP)
**Язык интерфейса:** русский; английский — язык игрового мира
**Целевая аудитория MVP:** дети и подростки 6–15 лет с нулевым или почти нулевым английским, в двух возрастных режимах: «младший» (6–9) и «старший» (10–15), см. раздел 4.7
**Платформа:** браузер (Chrome, Edge, Safari на ПК, планшете и телефоне), устанавливается как PWA

# 1. ГЛАВНАЯ ГИПОТЕЗА MVP

MVP должен ответить на один вопрос:

> **Возвращается ли ребёнок к игре по своему желанию, и может ли он через 2–3 недели реально сказать и понять то, чему игра его учила?**

Всё, что не помогает ответить на этот вопрос, в MVP не нужно.

Критерий успеха, который будем проверять на реальных детях:
- ребёнок сам просит поиграть хотя бы 3 раза в неделю;
- через 2–3 недели может вслух поздороваться, назвать себя, назвать 10+ предметов, цвета и числа до 10, понять простые инструкции (`Open the door`, `Find the red ball`);
- подросток 10–15 лет не бросает игру в первые 15 минут из-за того, что она «для малышей» (проверяется отдельно на 2–3 подростках).

# 2. ТЕХНОЛОГИИ (зафиксированы, не менять без согласования)

| Слой | Выбор | Почему |
|---|---|---|
| Язык | TypeScript | типы защищают учебные данные от ошибок |
| Сборка | Vite | быстро, просто, статический результат |
| Игровой движок | Phaser 3 (2D, вид сверху / лёгкая изометрия) | надёжно работает в браузере на слабых устройствах |
| UI поверх игры | обычный HTML/CSS (без тяжёлых фреймворков) | крупные кнопки, доступность, простота |
| Хранение прогресса | IndexedDB (через небольшую обёртку) | работает офлайн |
| Офлайн | Service Worker, PWA | игра запускается без интернета |
| Хостинг | GitHub Pages | бесплатно, уже используется автором |
| Озвучка | **заранее сгенерированные** аудиофайлы (TTS на этапе сборки) | ноль затрат во время игры, работает офлайн |
| Распознавание речи | Web Speech API там, где есть; иначе — режим «послушай и выбери» | бесплатно; не блокирует игру без микрофона |
| Сервер | **в MVP не нужен** | — |

Опционально на последнем этапе (только после проверки ядра): маленький прокси (Cloudflare Worker или Supabase Edge Function) для AI-диалогов. API-ключи **никогда** не попадают в клиентский код.

Графика: бесплатные ассеты с лицензией CC0 (Kenney.nl, OpenGameArt с проверкой лицензии). Лицензию каждого пакета записывать в `assets/LICENSES.md`.
Нельзя использовать персонажей, логотипы и стиль известных брендов, мультфильмов и игр.

# 3. ЧТО ВХОДИТ В MVP

## 3.1. Мир
**Один маленький городок** из 4 локаций, переход между ними через двери / края карты:

1. **Дом героя** — комнаты, предметы, семья (фото на стене, мама/папа/брат/сестра как NPC).
2. **Улица и парк** — животные, цвета, числа (посчитать уток, найти красный шарик).
3. **Магазин** — фрукты, игрушки, `How many?`, `Here you are`, `Thank you`.
4. **Школа** — школьные предметы, приветствия, простые инструкции учителя.

Каждая локация — отдельная сцена Phaser. Мир не одна большая карта.

## 3.2. Герой
- В начале выбирается возрастной режим (младший / старший); его можно сменить в родительском экране.
- Выбор из **6–8 готовых персонажей**: мальчики и девочки, разная внешность, **половина выглядит как подростки**. Конструктора лиц нет.
- Имя вводит ребёнок или родитель.
- Управление: стрелки/WASD на ПК; **касание экрана = идти туда** на планшете и телефоне.
- Взаимодействие: подойти к предмету/NPC → появляется крупная кнопка действия.

## 3.3. Спутник
Один спутник (животное-помощник, придуманный персонаж, не копия известного).
Он:
- ходит за героем;
- подсказывает, куда идти (стрелка/«пузырь»), когда ребёнок долго ничего не делает;
- **повторяет слово по-английски**, если нажать на него;
- радуется успехам (анимация + короткая фраза);
- задаёт повторение забытых слов прямо в мире: «Смотри! What colour is it?».

Частота реплик спутника — настройка (редко / нормально / часто). Выбора характера в MVP нет.

## 3.4. Задания (квесты)
Минимум **12 квестов** в 4 локациях, каждый на 2–5 минут. Примеры:
- «Мама просит принести `the blue cup`» — найти нужный предмет среди похожих.
- «Посчитай уток в пруду и скажи, сколько их» — выбрать / сказать число.
- «Купи 3 яблока» — понять продавца, выбрать количество, сказать `Thank you`.
- «Учитель говорит: `Open your book`, `Stand up`» — выполнить инструкцию.

Квест = последовательность шагов, описанная **в данных (JSON)**, а не в коде.

## 3.5. Диалоги
Три режима ответа, игра сама выбирает подходящий по уровню слова:
1. **Послушай и выбери** (картинки, без чтения) — для новых слов.
2. **Собери из карточек** — для фраз из 2–4 слов.
3. **Скажи вслух** — для уже знакомых слов и фраз, если микрофон доступен и разрешён.

4. **Напиши слово** — только в старшем режиме: ввод короткого слова (до ~8 букв) с допуском на одну опечатку. В младшем режиме ввода текста нет.

**Аудио первично.** Ребёнок, который ещё плохо читает, должен проходить всю игру: каждое английское слово озвучено, у каждой инструкции есть иконка/картинка, русская подсказка тоже может быть озвучена.

## 3.6. Награды
- Звёзды за квесты.
- **Коллекция**: карточки предметов и животных, которые ребёнок «выучил». Открытая карточка = слово освоено, нажал — слово звучит. В младшем режиме оформлена как альбом наклеек, в старшем — как коллекционные карточки / энциклопедия городка.
- Косметика для комнаты героя (3–5 предметов за звёзды).

Нет валюты, магазина за реальные деньги, случайных призов, рекламы, таймеров «вернись завтра, иначе потеряешь».

## 3.7. Родительский экран
Вход через простую «родительскую проверку» (например, пример на умножение).

Показывает:
- **«Что ребёнок уже умеет»** — список can-do утверждений (см. раздел 4.3), каждое со статусом: ещё не начато / в процессе / **подтверждено**;
- выученные слова (по альбому);
- слова, которые часто путаются;
- время игры по дням за последние 2 недели;
- настройки: лимит времени в день, микрофон вкл/выкл, частота реплик спутника, сброс прогресса, экспорт/импорт прогресса файлом (резервная копия).

# 4. УЧЕБНОЕ ЯДРО (самая важная часть)

## 4.1. Содержание Pre-A1, «Unit 1»
Около **100 слов и 20 фраз**:
- приветствия и прощания: `Hello`, `Hi`, `Goodbye`, `Bye`, `Good morning`;
- знакомство: `What's your name?`, `My name is…`, `I'm…`;
- цвета (8–10);
- числа 1–10;
- семья: `mum`, `dad`, `brother`, `sister`, `grandma`, `grandpa`, `baby`;
- животные (10–12);
- предметы дома и школы (20–25);
- еда и фрукты (10–12);
- инструкции: `Open`, `Close`, `Find`, `Give me`, `Stand up`, `Sit down`, `Look`, `Listen`;
- вежливость: `Please`, `Thank you`, `Yes`, `No`, `Here you are`.

Грамматика неявная, через образцы: `It's a…`, `It's red`, `I've got…`, `How many…?`, повелительное наклонение. В младшем режиме грамматических объяснений нет. В старшем — кнопка «Почему так?» у фразы: объяснение по-русски в 1–2 предложения, только по запросу.

Перед написанием контента сверить список со словарём Cambridge Pre A1 Starters и отметить расхождения в `docs/DECISIONS.md`.

## 4.2. Хранение контента
Весь учебный контент — в `content/` в виде JSON, отдельно от кода:

```
content/
  vocabulary.json     # слово, перевод, тема, картинка, аудио (US/UK), уровень
  phrases.json        # фраза, перевод, слова из словаря, аудио
  can_do.json         # навыки и правила их подтверждения
  quests/             # по одному файлу на квест
  dialogues/          # диалоги NPC
```

Добавить JSON Schema для каждого типа и **скрипт проверки контента** (`npm run validate-content`): нет ссылок на несуществующие слова, у каждого слова есть аудио и картинка, у каждого квеста достижимый конец.

## 4.3. Can-do утверждения и подтверждение навыка
Отчёт родителю строится не на «пройдено уроков», а на подтверждённых навыках. Пример:

| Навык | Подтверждён, когда… |
|---|---|
| Может поздороваться и попрощаться | правильно использовал приветствие в 3 разных диалогах в разные дни |
| Может назвать своё имя | ответил на `What's your name?` 3 раза, минимум 1 раз голосом (если микрофон включён) |
| Знает цвета | правильно определил 8 из 10 цветов в заданиях повторения через ≥ 2 дня после изучения |
| Считает до 10 | правильно решил 5 заданий на счёт подряд в разных локациях |
| Понимает простые инструкции | правильно выполнил 6 из 8 разных инструкций |

Правила подтверждения лежат в `can_do.json`, а не в коде.

## 4.4. Интервальное повторение
- Для каждого слова и фразы хранится состояние: когда видел, сколько раз верно/неверно, когда показать снова.
- Начать с простого алгоритма (лестница Лейтнера: 1 день → 2 → 4 → 7 → 14 дней), спрятанного за интерфейсом, чтобы позже можно было заменить на FSRS без переписывания игры.
- Повторение **встроено в мир**: спутник спрашивает, NPC просит принести забытый предмет, на улице появляется «предмет-загадка». Отдельного экрана «карточки» в MVP нет.
- В сессии не больше ~30% повторения, остальное — движение по сюжету и новое.

## 4.5. Учёт ошибок
- Записывать **какое слово с каким путали** (например `blue` ↔ `green`).
- Частые пары путаницы чаще попадают в повторение и выводятся в родительский отчёт.
- Не исправлять ребёнка посреди действия. После неверного ответа — повторить правильное слово голосом, дать ещё одну попытку, затем подсказку спутника. Никаких «красных крестиков» и звуков провала.

## 4.6. Говорение
- «Скажи вслух» — только для слов, которые ребёнок уже узнаёт на слух.
- Распознавание сравнивает **результат распознавания** с ожидаемым словом/фразой с допуском (несколько вариантов, нечёткое сравнение).
- Если распознавание не уверено → считать попытку «нейтральной», не ошибкой. Плохой микрофон не должен наказывать ребёнка.
- В MVP **нет оценки произношения** по звукам, ударению и интонации. Не делать вид, что она есть.
- Голос ребёнка не записывать и не сохранять.

## 4.7. Возрастные режимы
Мир, квесты и учебное ядро **общие**. Режим меняет только подачу; все различия задаются настройками и полями в контенте, а не отдельным кодом.

| | Младший (6–9) | Старший (10–15) |
|---|---|---|
| Тон текстов и спутника | ласковый, много похвалы | дружеский, без сюсюканья, с юмором |
| Подсказки на русском | озвучены, по умолчанию включены | текстом, можно отключить |
| Режимы ответа | 1–3 | 1–4 (добавлен ввод слова) |
| Грамматика | нет | «Почему так?» по запросу |
| Темп | медленнее, больше повторов | быстрее, меньше повторов знакомого |
| Награды | наклейки, звёзды | карточки, звёзды, испытания на время по желанию |
| Квесты | бытовые поручения | те же цели, но сюжетная обёртка: загадка, «расследование», поиск пропажи |

В квестах хранить **тексты для обоих режимов** (`text.junior`, `text.senior`); если поле `senior` не заполнено, используется `junior`.

## 4.8. Быстрая входная проверка
Многие подростки уже знают часть Pre-A1 из школы. При первом запуске (по желанию, можно пропустить):
- 3–4 минуты, около 25 слов и 5 фраз, формат «послушай и выбери»;
- узнанные слова получают статус «знакомо, нужно подтверждение» — они реже вводятся как новые, но всё равно попадают в повторение и подтверждаются в квестах;
- результат не показывается как оценка, только как «Отлично, многое ты уже знаешь — начнём с нового».

Если проверка показывает, что почти весь Unit 1 знаком, игра честно говорит: «Этот городок для начинающих; следующие уровни появятся позже», — и предлагает пройти его быстро. Число таких случаев фиксировать в журнале: это сигнал, нужен ли A1 раньше, чем планировалось.

# 5. ОЗВУЧКА

- Все английские слова и фразы озвучены заранее и лежат как файлы (`.mp3`/`.ogg`) в `assets/audio/`.
- Скрипт `npm run generate-audio` генерирует недостающие файлы через выбранный TTS-сервис (ключ — только в локальной переменной окружения, не в репозитории).
- Минимум два голоса: женский и мужской. Американский вариант по умолчанию, британский — если укладывается в бюджет; выбор в настройках.
- Кнопка **«медленно»** (заранее сгенерированная замедленная версия или воспроизведение с rate 0.75).
- Русские подсказки тоже могут быть озвучены (для детей, которые плохо читают).

# 6. ЧТО НЕ ВХОДИТ В MVP

Не делать, не начинать, не создавать заготовок:

- 3D-графику, Godot, открытый мир;
- другие миры и регионы, кроме городка;
- конструктор персонажа (лица, причёски и т.п.);
- выбор характера спутника, «память» спутника;
- строительство, фермы, крафт;
- транспорт;
- мультиплеер и любое общение между игроками;
- аккаунты, регистрацию, облачные сохранения, сервер;
- подписки, оплату, магазин за деньги;
- уровни A1, A2, B1 (только Pre-A1, Unit 1);
- ввод текста длиннее одного слова (предложения, сочинения);
- оценку произношения;
- свободный AI-разговор (кроме опционального этапа 6);
- Windows-установщик (PWA устанавливается из браузера).

# 7. ЭТАПЫ

Каждый этап заканчивается **работающей сборкой на GitHub Pages**, которую можно открыть на телефоне. Не переходить к следующему этапу без проверки текущего.

### Этап 0. Архитектура (только документы, без кода игры)
- структура каталогов;
- схемы данных (JSON Schema) для словаря, фраз, квестов, диалогов, can-do;
- схема хранения прогресса в IndexedDB;
- список ассетов и их лицензий;
- риски и как их снижать.

**Результат:** `docs/ARCHITECTURE.md`, `docs/DATA_SCHEMAS.md`, `docs/RISKS.md`. Ждать согласования.

### Этап 1. Ходячий мир
- проект Vite + TypeScript + Phaser, сборка и деплой на GitHub Pages;
- одна локация (дом), герой, управление клавиатурой и касанием, камера следует за героем;
- взаимодействие с 3 предметами (нажал → слово звучит, показывается картинка и слово);
- сохранение позиции и настроек в IndexedDB;
- экран настроек (громкость, масштаб интерфейса).

**Проверка:** открыть на ПК и на телефоне, походить, перезагрузить страницу — позиция сохранилась.

### Этап 2. Учебное ядро
- загрузка контента из JSON + скрипт проверки контента;
- движок квестов по данным;
- три режима ответа (послушай-выбери, собери, скажи вслух с запасным вариантом);
- интервальное повторение и учёт путаницы;
- 3 квеста в доме.

**Проверка:** автотесты на алгоритм повторения, подтверждение can-do и проверку контента; пройти 3 квеста.

### Этап 3. Весь городок
- остальные 3 локации, 12+ квестов, NPC, спутник с подсказками и повторением в мире;
- весь контент Unit 1 + озвучка;
- альбом наклеек, звёзды, украшения комнаты.

- оба возрастных режима и входная проверка.

**Проверка:** полное прохождение без застреваний в обоих режимах; ребёнок 6–9 лет проходит первые 15 минут без помощи взрослого; подросток 11–15 лет играет 15 минут и не называет игру «детской» (тесты на реальных детях).

### Этап 4. Родительский экран
- can-do отчёт, слова, путаница, время;
- лимит времени, микрофон, экспорт/импорт прогресса.

**Проверка:** отчёт совпадает с тем, что ребёнок реально делал в игре (сверить вручную по журналу событий).

### Этап 5. Офлайн и полировка
- Service Worker, установка как PWA, игра работает в режиме самолёта;

# 8. КРИТЕРИИ ГОТОВНОСТИ MVP

1. Игра открывается по ссылке и ставится как PWA на ПК, Android и iPad.
2. Работает без интернета после первой загрузки.
3. Все 4 локации и 12+ квестов проходятся от начала до конца.
4. Все ~100 слов и 20 фраз озвучены, у каждого есть картинка.
5. Интервальное повторение реально возвращает забытые слова (проверено тестами и вручную на «сдвинутой» дате).
6. Родительский отчёт показывает только подтверждённые навыки.
7. Прогресс не теряется при перезагрузке; есть экспорт/импорт.
8. Нет ни одной кнопки, которая ничего не делает.
9. Нет внешних запросов во время игры (кроме опционального этапа 6).
10. `npm test` и `npm run validate-content` проходят без ошибок.
11. Есть `README.md`: как запустить, как собрать, как добавить слово / квест.
