## Что остаётся до проверки главной гипотезы

Раздел 1 мастер-промпта: **«Возвращается ли ребёнок к игре сам, и может ли через 2–3 недели сказать то, чему игра учила?»** Ни один автотест на это не отвечает. Нужно:

1. Опубликовать на GitHub Pages (нужен пустой репозиторий — см. README).
2. Дать поиграть 2–3 детям 6–9 лет и 2–3 подросткам 11–15 лет, 2–3 недели.
3. Смотреть родительский экран: дни с игрой, подтверждённые навыки, путаницу.
4. Через 2–3 недели — короткая устная проверка ребёнка без игры.
5. Попросить преподавателя проверить английский в `content/phrases.json`.
