| D7 | Распознавание речи — только на устройстве; кандидат Vosk с ограниченным словарём | Голос ребёнка не покидает устройство (см. RISKS R2) | 🔬 |
| D8 | У NPC фиксирован пол голоса, акцент выбирает игрок | Иначе настройка «британский английский» не действовала бы на половину персонажей | ✅ |
| D9 | Интервальное повторение: сначала лестница Лейтнера (1→2→4→7→14 дней) за интерфейсом `Scheduler` | Просто, понятно, тестируемо; FSRS можно подставить позже | ✅ |
| D10 | Ответы с подсказкой и `unsure` не засчитываются в навыки | Отчёт родителю должен отражать самостоятельные навыки | ✅ |
| D11 | Журнал хранит сырые события; статус навыков — пересчитываемый кэш | Пороги навыков будут меняться после тестов (RISKS R7) | ✅ |
| D12 | `find_item` пишет событие по каждому слову предмета | Различает «не знает цвет» и «не знает предмет» | ✅ |
| D13 | Лимит 6 новых элементов на квест | Не перегружать начинающего; проверяется схемой | ✅ |
| D14 | Сверка словаря с официальным списком Cambridge Pre A1 Starters | Пометки «есть в списке» в контенте не ставим, пока не сверено по официальному документу | 🔬 этап 2 |
| D15 | ID контента не переименовываются после выпуска | На них ссылается сохранённый прогресс | ✅ |
| D16 | Время в учебном ядре — только через `Clock` | Тесты «перематывают» дни для проверки повторения | ✅ |
| D17 | Пока нет файлов озвучки — голос браузера (speechSynthesis) | Работает без интернета на Windows, Android, iPhone; качество зависит от устройства. Когда на Этапе 2 появятся файлы — они используются первыми, голос браузера остаётся запасным. Если на устройстве нет английского голоса — карточка честно об этом пишет | ✅ этап 1 |
| D18 | Графика нарисована кодом (`src/game/art/`), а не скачана | Нет вопросов с лицензиями, единый стиль, цвета героя параметризованы — из того же кода получатся 6–8 персонажей. Если понадобится уровень выше — заменить на работу пиксель-художника, не меняя код сцены | ✅ этап 1 |

| D21 | Касание предмета: герой сам подходит к нему и открывает карточку | Для детей на планшете это естественнее, чем «дойди, потом нажми кнопку» | ✅ |
