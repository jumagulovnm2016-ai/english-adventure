# Журнал решений

| D1 | Браузер, Phaser 3 (2D), TypeScript, Vite; Godot и 3D — не в MVP | Работает на слабых устройствах и в браузере; привычный автору стек (GitHub Pages) | ✅ (мастер-промпт) |
| D2 | Визуальный стиль — пиксель-арт, тайлы 16×16, масштаб ×3–×4 | Нейтрален для 6–15 лет (не «малышовый»), много бесплатных CC0-наборов, легко держать единый стиль | ⏳ |

| D5 | Озвучка генерируется заранее и лежит файлами `assets/audio/<акцент>_<пол>/<id>.mp3` | Ноль затрат и запросов во время игры, работает офлайн | ✅ |
| D6 | TTS-сервис для генерации | Выбрать сравнением на слух 2–3 сервисов (с американскими и британскими нейроголосами) и проверкой условий использования. **Перенесено:** из рабочей среды внешние TTS-сервисы недоступны, и нужен ключ заказчика. До решения — голос браузера (D17) | ⏳ ждёт заказчика |
| D7 | Распознавание речи — только на устройстве; кандидат Vosk с ограниченным словарём | Голос ребёнка не покидает устройство (см. RISKS R2). **Этап 2:** готовы сравнение распознанного текста с ожидаемым (`matchSpoken`, с исходом «не уверен») и лестница помощи с переходом на другой режим; сам режим «скажи вслух» не включается, пока проба не проведена на реальных устройствах и детских голосах | 🔬 нужна проба на устройстве |
| D8 | У NPC фиксирован пол голоса, акцент выбирает игрок | Иначе настройка «британский английский» не действовала бы на половину персонажей | ✅ |
| D9 | Интервальное повторение: сначала лестница Лейтнера (1→2→4→7→14 дней) за интерфейсом `Scheduler` | Просто, понятно, тестируемо; FSRS можно подставить позже | ✅ |
| D10 | Ответы с подсказкой и `unsure` не засчитываются в навыки | Отчёт родителю должен отражать самостоятельные навыки | ✅ |
| D11 | Журнал хранит сырые события; статус навыков — пересчитываемый кэш | Пороги навыков будут меняться после тестов (RISKS R7) | ✅ |
| D12 | `find_item` пишет событие по каждому слову предмета | Различает «не знает цвет» и «не знает предмет» | ✅ |
| D13 | Лимит 6 новых элементов на квест | Не перегружать начинающего; проверяется схемой | ✅ |
| D14 | Сверка словаря с официальным списком Cambridge Pre A1 Starters | Пометки «есть в списке» в контенте не ставим, пока не сверено по официальному документу | 🔬 этап 2 |
| D15 | ID контента не переименовываются после выпуска | На них ссылается сохранённый прогресс | ✅ |
| D16 | Время в учебном ядре — только через `Clock` | Тесты «перематывают» дни для проверки повторения | ✅ |
| D17 | Пока нет файлов озвучки — голос браузера (speechSynthesis) | Работает без интернета на Windows, Android, iPhone; качество зависит от устройства. Когда на Этапе 2 появятся файлы — они используются первыми, голос браузера остаётся запасным. Если на устройстве нет английского голоса — карточка честно об этом пишет | ✅ этап 1 |
| D18 | Графика нарисована кодом (`src/game/art/`), а не скачана | Нет вопросов с лицензиями, единый стиль, цвета героя параметризованы — из того же кода получатся 6–8 персонажей. Если понадобится уровень выше — заменить на работу пиксель-художника, не меняя код сцены | ✅ этап 1 |
| D19 | Phaser 3.90, а не вышедший Phaser 4 | Мастер-промпт фиксирует Phaser 3; ветка 3 зрелая и хорошо документирована. Переход на 4 — отдельная задача после MVP, если появится причина | ✅ |
| D20 | Движение героя считается по реальным часам, а не по времени кадра Phaser | Phaser сглаживает время кадра и при низком FPS занижает его — на слабых устройствах герой ходил бы медленнее (поймано сквозным тестом) | ✅ |
| D21 | Касание предмета: герой сам подходит к нему и открывает карточку | Для детей на планшете это естественнее, чем «дойди, потом нажми кнопку» | ✅ |
| D22 | Карты описаны строками в TypeScript (`src/game/maps/`) | На этапе 3 решено **не** переходить на Tiled: 4 карты по 10–20 клеток удобно править текстом, а автотесты (`tests/maps.spec.ts`) проверяют проходимость, двери и места для предметов. Tiled — когда карты станут больше | ✅ пересмотрено на этапе 3 |
| D23 | Акцент по умолчанию — британский; стиль — пиксель-арт | Заказчик не ответил на вопрос; оба значения меняются в одном месте (`DEFAULT_SETTINGS`, `art/`) | ⏳ ждёт подтверждения |
| D24 | Реакция на ответ — сразу, запись в журнал — параллельно | На медленных устройствах запись в IndexedDB занимает ~0,2 с на событие; ребёнок не должен ждать (поймано сквозным тестом) | ✅ этап 2 |
| D25 | В лестницу Лейтнера идёт только первая попытка задания; ответ с подсказкой или со второй попытки не продвигает; продвижение — не раньше срока | Иначе слово «выучивается» за один вечер нажатием наугад | ✅ этап 2 |
| D26 | Варианты для фраз — другие фразы, которые ребёнок должен уметь говорить (даже ещё не пройденные) | Ребёнок слышит каждый вариант по кнопке 🔊; незнакомая фраза в вариантах — тоже знакомство | ✅ |
| D27 | Персонаж появляется в доме, когда открыт его первый квест (Эми — после квеста мамы) | Ребёнок не видит «пустых» персонажей, с которыми не о чем говорить | ✅ |
| D28 | Отладочные хуки `window.__game/__quests/__learning/__tasks` в сборке | Нужны сквозным тестам; безвредны (ничего не отправляют). Можно спрятать за флаг сборки перед публичным запуском | ⏳ |
| D29 | Локации открываются по сюжету: улица — после домашних квестов, магазин и школа — после квеста Бена | Ребёнок не теряется в пустом городе; закрытая дверь объясняет, что сделать | ✅ этап 3 |
| D30 | Возраст не сохраняется — только выбранный режим «6–9 / 10–15» | Меньше личных данных | ✅ |
| D31 | Входная проверка — только картинки, без подписей, один ответ, кнопка «Не знаю» | Проверяем понимание на слух, а не чтение и не угадывание. Узнанное — «знакомо», подтверждается повторением через день; случайное угадывание (1 из 3) не делает слово выученным | ✅ |
| D32 | «Выбери» бывает двух видов: «ответь на вопрос» (подписи + 🔊) и «послушай и найди» (только картинки) | Инструкции учителя и слова-картинки проверяют понимание на слух; вопросы «What colour…?» — понимание вопроса | ✅ |

| D34 | Словарь — только слова, которые учатся в квестах (57), а не список «на будущее» | Слово, которого нет ни в одном квесте, ребёнок никогда не встретит | ✅ |
