# Отчёты по этапам

## Этап 1 — Ходячий мир (17.11.2026)

**Что сделано**
- Проект Vite + TypeScript + Phaser 3.90; сборка в обычном виде (`dist/`, для GitHub Pages) и одним файлом (`dist-single/index.html`).
- Дом героя 20×14 клеток: кухня и комната, мебель, окна, дверь. Вся графика нарисована кодом (D18).
- Герой: 4 направления, анимация ходьбы, тень. Управление: стрелки, WASD, мышь, касание.
- Касание пола — герой идёт туда, обходя мебель (поиск пути A* + сглаживание). Касание предмета — подходит и показывает карточку (D21).
- Камера следует за героем; масштаб подстраивается под экран (ПК — 16×11 клеток, телефон — 8×14); если комната меньше экрана — она по центру.
- Три говорящих предмета: синяя чашка, красный мяч, зелёная книга. Над ближайшим — «!», появляется кнопка «👀 Посмотреть», работает клавиша E/пробел/Enter.
- Карточка: картинка, «blue cup» / «синяя чашка», слова по отдельности (нажал — звучит), «Ещё раз», «Медленно». Русские названия согласуются по роду автоматически.
- Сохранение в IndexedDB: позиция (раз в 5 с и при сворачивании), настройки — сразу. Кнопка «Продолжить» при повторном входе. Если браузер не даёт сохранять — об этом сказано на экране.
- Настройки: громкость, размер интерфейса (3 ступени), британский/американский, женский/мужской голос, проверка звука.

**Файлы:** `index.html`, `vite.config.ts`, `tsconfig.json`, `src/**` (новые), `tests/*.spec.ts`, `tests/e2e/smoke.mjs`, `.github/workflows/deploy.yml`, `content/items.json` (+2 предмета), документы.

**Как запустить**
```bash
npm install
npm run dev            # http://localhost:5173 — режим разработки
npm run build          # проверка контента + типы + сборка в dist/
npm run build:single   # один файл dist-single/index.html — можно открыть двойным щелчком
```

**Как проверить (вручную)**
1. Нажать «Играть». Походить стрелками/WASD — герой упирается в стены и мебель.
2. Нажать мышью на пол — герой идёт туда в обход мебели.
3. Нажать на мяч на ковре — герой подходит, открывается карточка «red ball», звучит слово.
4. Нажать на «red» и «ball» по отдельности, «Медленно». Закрыть Esc или ✕.
5. Открыть ⚙, выбрать «Крупный» и «Американский». Перезагрузить страницу — кнопка «Продолжить», герой там же, настройки сохранились.
6. Открыть на телефоне: касание пола и предметов.

## Этап 2 — Учебное ядро (17.11.2026)

**Что сделано**
- **Учебное ядро** (`src/learning/`, без Phaser, полностью покрыто тестами):
  - интервальное повторение — лестница Лейтнера 0→1→2→4→7→14 дней; в лестницу идёт только первая попытка; с подсказкой не продвигает; раньше срока не продвигает (нельзя «выучить» за вечер);
  - статусы слова: новое → учим → выучено (≈ неделя без ошибок) → снова учим при ошибке;
  - журнал событий: что, где, верно ли, с подсказкой ли, что выбрал вместо верного;
  - учёт путаницы (пары «blue ↔ green»), выбор слов для повторения (сначала путаемые и давно ждущие);
  - выбор режима ответа по знанию слова и возрасту;
  - проверка ответов: выбор, сборка фразы, ввод слова (одна опечатка или перестановка букв допустимы), голос (с исходом «не уверен» — готово, но не включено, D7);
  - подтверждение навыков «умеет» по трём типам правил из `can_do.json` (для отчёта родителю на Этапе 4).
- **Движок квестов и диалогов** (`src/quests/`): граф реплик с ветками, «лестница помощи» (ошибка → ещё попытка → подсказка → показ ответа; застрять нельзя), восстановление квеста после перезагрузки.
- **Три квеста в доме:**
  1. «Синяя чашка для мамы» — поздороваться, найти синюю чашку среди красной и зелёной чашек и синей тарелки, отнести, ответить на вопрос о цвете, сказать спасибо и до свидания. Награда — синяя лампа в комнату.
  2. «Новая соседка» — Эми (приходит после 1-го квеста): Hello! I'm Amy. → What's your name? → My name is … В конце — повторение пройденного.
  3. «Мяч для папы» — найти красный мяч среди синего мяча, красной книги и зелёной чашки; отдать со словами «Here you are».
- **Задания на экране:** «выбери ответ» (у каждой фразы кнопка 🔊 — можно играть, не умея читать), «послушай и найди» (цвета кружками, предметы картинками, числа цифрами), «собери фразу», «напиши слово» (только старший режим).
- **В мире:** мама, папа, Эми с «!» над тем, с кем нужно поговорить; предметы квеста раскладываются по местам на кухне или в комнате; взятый предмет — над головой героя; цель квеста и звёзды в шапке; окно начала квеста и окно награды со списком новых слов.
- Звуки «верно / не то» — мягкие, без «наказания».

**Автотесты:** 82 модульных (из них 67 — учебное ядро и квесты), 16 проверок контента, 20 сквозных проверок управления и **16 сквозных проверок полного прохождения трёх квестов** в Chrome: с ошибками, подсказкой, показом ответа, правильной записью ошибок по словам, повторением, наградами, сохранением и продолжением квеста после перезагрузки на телефоне.

**Сквозные тесты поймали и помогли исправить:** задержку реакции на ответ из-за ожидания записи в базу (D24); отсутствующее слово «lamp» (в награде было «синий» вместо «синяя лампа»).

**Как проверить вручную**
1. «Играть» → подойти к маме (над ней «!») → «Поговорить».
2. Нарочно ошибиться в «поздоровайся» 3 раза — увидеть «попробуй ещё», подсказку и показ ответа.
3. Найти синюю чашку: сначала взять синюю тарелку — услышать «blue plate», появится «Нужно другое».
4. Отнести чашку маме, пройти вопросы, получить ⭐⭐⭐ и лампу в комнате.
5. Появится Эми → квест 2; потом папа → квест 3.
6. Перезагрузить посреди «найди» — квест продолжится с того же шага.

**Что НЕ сделано на этом этапе и почему**
- **Озвучка записанными голосами (D6)** — нужен ваш выбор сервиса и ключ; внешние TTS-сервисы из рабочей среды недоступны. Пока — голос браузера.
- **Режим «скажи вслух» (D7)** — проверка ответа готова и протестирована, но режим не включается, пока распознавание на устройстве не проверено на детских голосах на реальных телефонах/планшетах.
- **Сверка словаря с официальным списком Cambridge Pre A1 Starters (D14)** — официальный документ недоступен из рабочей среды; нужно сверить по PDF Cambridge.

**Следующий этап — 3. Весь городок:** улица, магазин, школа; 12+ квестов; спутник с подсказками и повторением в мире; выбор героя; оба возрастных режима; входная проверка; весь контент Unit 1.

## Этап 3 — Весь городок (18.11.2026)

**Что сделано**
- **4 локации:** дом, улица с парком и прудом, магазин, школа. Двери — настоящие (герой входит в дверь сам). Улица открывается после домашних квестов, магазин и школа — после квеста Бена; закрытая дверь говорит, что сделать (D29). Английские вывески HOME, SHOP, SCHOOL.
- **12 квестов** (было 3):
  - дом: синяя чашка, соседка Эми, мяч для папы;
  - улица: утки в пруду (счёт до 6, цвет), потерявшаяся кошка (black/white, cat/dog), животные (bird, rabbit, frog — «What's this?» с картинкой);
  - магазин: яблоки для мамы — **через три локации** (мама дома → магазин «Three apples, please» → обратно к маме), фрукты на полке, завтрак (два поиска подряд);
  - школа: первый урок (Good morning, Stand up / Sit down / Open / Close your book — понимание на слух по картинкам), карандаш Тома (pencil/pen/ruler), счёт книг на партах.
- **Контент:** 57 слов, 58 фраз (из них 14 — сказать самому), 31 предмет, 8 жителей, 23 диалога, 10 навыков для отчёта родителю.
- **Первый запуск:** 6 героев на выбор (разная внешность), имя, режим «6–9 / 10–15 лет» (возраст не сохраняется — D30), необязательная входная проверка на 30 слов (только картинки, D31).
- **Возрастные режимы:** у каждого квеста два названия и вступления, подсказки на разном языке; в старшем — ввод слова с клавиатуры. Переключается в настройках.
- **Спутник Пип** — лисёнок: ходит следом; если ребёнок долго ничего не делает — подсказывает, что делать и куда идти; иногда над ним «?» — вопрос на повторение. Кнопка 🦊 в шапке. Частота — в настройках (D35).
- **Новые настройки:** режим, частота подсказок Пипа, перевод на русский — показывать/скрывать.
- **Новая графика** (вся нарисована кодом): трава, дорожки, пруд, живая изгородь, 3 здания, деревья, скамейка, цветы, полки, прилавок, доска, парты; 20 новых предметов (животные, еда, школьные вещи); 6 героев, 5 новых жителей, Пип. Лист предпросмотра: `npm run art-preview`.

**Автотесты:** 104 модульных (в т. ч. все 4 карты: проходимость, двери туда и обратно, места для предметов; вся цепочка квестов проходима), 16 проверок контента, сквозные — 20 (управление) + 16 (квесты дома) + **25 (весь городок: все 12 квестов подряд, двери, спутник, режимы, сохранение, телефон)**.

**Сквозные тесты поймали и помогли исправить:** спутник вставал на героя; в входной проверке были подписи-слова (проверялось чтение, а не слух); навыки «не начато» после десятка «Hello» (D33); Phaser переиспользует объект сцены при смене локации — старые предметы «переезжали» бы в новую локацию.

**Как проверить вручную**
1. Открыть в новом окне браузера (или очистить данные сайта) — появится выбор героя.
2. Пройти входную проверку или пропустить.
3. Дом → попробовать выйти в дверь сразу (🔒) → пройти 3 квеста → выйти на улицу.
4. Бен у пруда: посчитать уток. Потом магазин и школа откроются.
5. Мама даст поручение купить яблоки — сходить в магазин и вернуться.
6. Постоять минуту без дела — Пип подскажет. ⚙ → «Пип подсказывает: часто».
7. ⚙ → режим «10–15 лет» — названия квестов и подсказки станут «взрослее».

**Чего нет и почему**
- **~100 слов** по плану — сделано 57: в словарь вошли только слова, которые реально учатся в квестах (D34). Для 100 нужно ещё ~8 квестов (семья, дом, одежда, игрушки) — это контент, движок готов.
- **Озвучка записанными голосами (D6)** и **«скажи вслух» (D7)** — по-прежнему ждут решения и проверки на устройстве.
- **Английский в контенте не проверен преподавателем.**
- **Ни один ребёнок ещё не играл.** Это главный открытый вопрос всего MVP.

**Следующий этап — 4. Родительский экран:** что ребёнок умеет (по 10 навыкам), выученные слова, частые путаницы, время игры, лимит времени, экспорт/импорт прогресса.

## Этап 4 — Родительский экран (18.11.2026)

**Что сделано**
- **Вход для взрослых:** из настроек (⚙ → «Для родителей») и со стартового экрана. Пример на умножение; 3 ошибки — пауза 30 секунд. Можно задать **PIN из 4 цифр** — тогда только он (D36).
- **«Что умеет»** — 10 навыков: ✅ подтверждён (с датой), 🟡 учится (с полосой прогресса), ⚪ ещё не начато. Нажатие на навык показывает, как именно он проверяется. Пометка «без голоса», если навык подтверждён без микрофона.
- **Сводка:** заданий выполнено, навыков подтверждено, слов выучено, изучается сейчас, минут игры за неделю.
- **Слова:** таблицы «выучено / учит сейчас / знал раньше, проверяем» со счётом «верно / ошибок»; блоки «Чаще ошибается» и «Путает: blue ↔ red».
- **Время:** график за 14 дней, сегодня и лимит. Время считается только когда игра открыта на экране (D37).
- **Дневной лимит:** нет / 15 / 30 / 45 / 60 минут. По достижении — экран «На сегодня всё!», управление блокируется; «ещё 15 минут» — только через проверку взрослого.
- **Резервная копия:** сохранить прогресс в файл (имя латиницей, D39) и загрузить из файла — с проверкой по схеме и понятными ошибками; PIN в файл не попадает (D38).
- **Сброс прогресса** — только после ввода слова «СБРОС» (D40).
- Напоминание: все данные — только на устройстве.

**Автотесты:** 110 модульных (отчёт, файл прогресса туда-обратно, повреждённые и чужие файлы, лимит и смена дня), **14 сквозных проверок родительского экрана**: ребёнок проходит квест с двумя ошибками — отчёт показывает ровно эти ошибки («blue ↔ red», «cup ↔ plate») и те же счётчики, что в журнале; лимит останавливает игру; PIN; файл скачивается и проходит схему; сброс; загрузка возвращает прогресс (и лимит); чужой файл не портит прогресс; телефон. Регрессия этапов 1–3 — проходит.

**Тесты поймали и помогли исправить:** окно «Для взрослых» открывалось **под** экраном «На сегодня всё!» — родитель не смог бы продлить время; файл с кириллицей в имени сохранялся безымянным «download»; касание персонажа, рядом с которым стоял Пип, «съедал» Пип — теперь персонажи и предметы важнее.

**Как проверить вручную**
1. ⚙ → «Для родителей» → решить пример.
2. Посмотреть «Что умеет» и «Слова» после пары квестов (специально ошибитесь в одном).
3. «Настройки» → лимит 15 минут; поиграть — появится «На сегодня всё!»; «ещё 15 минут».
4. «Сохранить в файл» → «Начать заново» (СБРОС) → «Загрузить из файла».

**Ограничения**
- Внутри окна Claude скачивание идёт через разрешение «downloads» — браузер спросит подтверждение. На GitHub Pages — обычная загрузка.
- Подросток решит пример на умножение — для 10–15 лет нужен PIN.
- Один профиль на устройстве. Несколько детей на одном планшете — после MVP (BACKLOG).

**Следующий этап — 5. Офлайн и полировка:** установка как приложение (PWA), работа без интернета, проверка на слабом телефоне, доступность.

## Новое оформление (19.11.2026)

**Почему.** После публикации заказчик проверил игру на Android: работает, звук есть, офлайн работает, но «всё выглядит как битовый некачественный контент». Пиксельные спрайты 16 px, нарисованные кодом, действительно читались как временная графика.

**Что сделано.**
- Вся графика перерисована в мультяшном векторном стиле (образец утверждён заказчиком): 31 предмет, 19 предметов мебели и зданий, 14 персонажей × 4 направления × 3 кадра, Пип, пол четырёх карт (D45).
- Чёткость на телефонах: холст в физических пикселях (до ×2) с автоснижением на слабых устройствах (D46).
- Шрифт Nunito подключён офлайн (D47); стартовый экран — небо и луг с героем и Пипом; иконки приложения из нового Пипа.
- Исправлено попутно: пустые места между плашками HUD перехватывали касания (под ними нельзя было нажать на предмет).

**Проверка.** 111 модульных тестов (новые: целостность всех SVG, размеры, кадры ходьбы), 100 сквозных проверок, замер скорости: ПК 44, средний телефон 58, слабый 54 кадра/с (программная отрисовка; после автоснижения разрешения).

**Риски.** Векторная графика тяжелее пиксельной по памяти (~20 МБ текстур) и по заполнению экрана; на очень старых телефонах возможны рывки в первые 3 секунды, пока не сработает автоснижение. Проверить на реальном слабом Android.
