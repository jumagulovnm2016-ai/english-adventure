# Бэклог — после MVP

Сюда записываются все идеи, которые не входят в MVP. Ничего отсюда не делается, пока MVP не проверен на детях.

## Учебное
- Unit 2–4 Pre-A1, затем A1, A2, B1 (по CEFR, с can-do для каждого уровня)
- Замена Лейтнера на FSRS
- Оценка произношения (звуки, ударение, интонация)
- Ввод предложений, короткие письменные сообщения (A1+)
- Режим полноценных уроков с грамматикой
- AI-наставник с объяснением ошибок после диалога

## Игровое
- Новые районы городка, затем другие миры (лес, острова, …)
- Выбор характера спутника, развитие спутника
- Строительство и украшение дома, ферма, крафт с инструкциями на английском
- Транспорт
- Питомцы, расширенные коллекции
- Переход в 3D (только если 2D-версия доказала, что учит и удерживает)

## Платформа
- Аккаунты, несколько детских профилей, облачная синхронизация
- Полноценный родительский кабинет на отдельном устройстве
- Windows-приложение
- Семейные задания, закрытые комнаты, безопасный мультиплеер с готовыми фразами
- Подписки (Free / Premium / AI Premium / Family) — без лутбоксов, рекламы и pay-to-win
